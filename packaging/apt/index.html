PBP APT repository

The signed Debian package repository for PBP (PVE Backup Proofing), by Breadth Security.

PBP takes the newest backup of every guest from your Proxmox Backup Server storage, restores it into a temporary guest on an isolated network, boots it and checks that it is healthy, on a schedule. This repository carries its final releases for amd64 and arm64, from 0.10.0 on.

There is nothing to browse here: APT reads the repository directly. Add it with the steps below.

Add the repository

As root, on the Proxmox VE node and on a separate PBP host alike:

curl -fsSLo /usr/share/keyrings/pbp-archive-keyring.gpg https://apt.breadthsecurity.com/pbp-archive-keyring.gpg
cat > /etc/apt/sources.list.d/pbp.sources <<'EOF'
Types: deb
URIs: https://apt.breadthsecurity.com
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/pbp-archive-keyring.gpg
EOF
apt update && apt install pbp

Then run pbp setup where PBP runs, on the node itself or on its own host; on its own host, it prints the pbp node setup command to run on the node. See Setup.

The signing key

APT checks every download against this key. Its fingerprint:

0D9A 64A2 3F04 1588 DE11 EE36 9B29 93CB 6BBA 9833

The key file is also signed with PBP's release key, the one that signs every release's checksums. To check both, see Check the key.

Upgrading

To upgrade only PBP: apt update && apt install --only-upgrade pbp. On a Proxmox VE node, a plain apt upgrade also upgrades Proxmox VE itself.

Upgrade the node and a separate PBP host in the same sitting: the daemon and the node helper must share their major.minor version. For the same reason, don't add this repository to unattended-upgrades. More in Upgrading.
